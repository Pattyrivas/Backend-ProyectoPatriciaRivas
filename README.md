# 🛒 E-commerce — Proyecto Backend I

Aplicación de e-commerce desarrollada como proyecto final del curso de Backend I en Coderhouse. Implementa un servidor con renderizado de vistas del lado del servidor para mostrar y gestionar productos.

## ✨ Funcionalidades

- Listado y gestión de productos
- Renderizado de vistas dinámicas con Handlebars
- Estructura de servidor con Node.js
- Persistencia de datos del catálogo

## 🛠️ Stack Tecnológico

- **Node.js** — entorno de ejecución del servidor
- **Express** — framework del servidor (handlers de rutas)
- **Handlebars (HBS)** — motor de plantillas para las vistas
- **JavaScript (ES6+)**
- **CSS3**

## 🚀 Cómo ejecutar el proyecto localmente

```bash
# Clonar el repositorio
git clone https://github.com/Pattyrivas/Backend-ProyectoPatriciaRivas.git

# Entrar a la carpeta
cd Backend-ProyectoPatriciaRivas

# Instalar dependencias
npm install

# Levantar el servidor
npm start
```

El proyecto quedará disponible en `http://localhost:8080` (o el puerto configurado en el proyecto).
